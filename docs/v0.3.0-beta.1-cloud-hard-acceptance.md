## 3. A：发布下载、安装与静态健康

### A1. 发布后下载复核

两个资产发布后，在全新 Cloud setup task 中执行：

```bash
set -Eeuo pipefail

TAG="v0.3.0-beta.1"
ZIP="pwf-codex-cloud-hooks-${TAG}.zip"
ZIP_SHA256="c9dd8bf5dea0f50662df0a15d653584b7d9a6f1f0329dfc3c2d55fe33a366f91"
BOOTSTRAP="/tmp/init-cloud-sandbox-v0.3.0-beta.1.bash"
BOOTSTRAP_SHA256="0c9d57f53ff980d9d207bc8291b1f055058000e45258732b19156ec93b8b1f2a"
BASE_URL="https://github.com/keeptoy/pwf-codex-cloud-hooks/releases/download/${TAG}"
PROBE_DIR="$(mktemp -d)"
trap 'rm -rf -- "$PROBE_DIR" "$BOOTSTRAP"' EXIT

curl --fail --location --retry 3 --output "$PROBE_DIR/$ZIP" "$BASE_URL/$ZIP"
curl --fail --location --retry 3 --output "$BOOTSTRAP" \
  "$BASE_URL/init-cloud-sandbox-v0.3.0.bash"
printf '%s  %s\n' "$ZIP_SHA256" "$PROBE_DIR/$ZIP" | sha256sum --check -
printf '%s  %s\n' "$BOOTSTRAP_SHA256" "$BOOTSTRAP" | sha256sum --check -

unzip -q "$PROBE_DIR/$ZIP" -d "$PROBE_DIR/package"
PACKAGE_ROOT="$PROBE_DIR/package/pwf-codex-cloud-hooks"
test "$(find "$PACKAGE_ROOT" -type f | wc -l)" -eq 22
test ! -e "$PACKAGE_ROOT/init-cloud-sandbox-v0.3.0.bash"
node -e 'const p=require(process.argv[1]); if(p.version!=="0.3.0-beta.1") process.exit(1)' \
  "$PACKAGE_ROOT/package.json"
python3 "$PACKAGE_ROOT/tools/build_release.py" check \
  --contract "$PACKAGE_ROOT/contracts/release-artifact-v1.json" \
  --archive "$PROBE_DIR/$ZIP"

echo "BETA1_ASSET_DOWNLOAD=PASS"
echo "BETA1_ZIP_ENTRIES=22"
echo "BETA1_BOOTSTRAP_EXTERNAL=PASS"
```

PASS：两个 `sha256sum` 均 OK，ZIP 22 entries、版本正确、bootstrap 不在 ZIP、builder check healthy。
